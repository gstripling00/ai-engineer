# Labs

Chapter labs belong here as Jupyter notebooks. Use one directory per chapter, for example `chapter-01-single-soc-agent/`, `chapter-02-tools/`, and so on through the final multi-agent chapter.

All notebooks must install from the repository-level `requirements.txt` rather than embedding package-specific `pip install` commands. Reusable logic should move into `src/aegis/` instead of being duplicated across notebooks.
