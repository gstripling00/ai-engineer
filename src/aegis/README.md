# Aegis Application Package

Production-oriented reusable code for the agent system lives here rather than inside notebooks.

Recommended modules:
- `agents/` — individual agent implementations and role contracts
- `orchestration/` — workflow, routing, handoffs, and multi-agent coordination
- `tools/` — tool adapters and schemas
- `memory/` — short- and long-term memory abstractions
- `rag/` — retrieval, indexing, grounding, and context assembly
- `security/` — guardrails, authorization, validation, sandboxing, and policy enforcement
- `observability/` — logging, tracing, metrics, and telemetry
- `evaluation/` — offline/online evaluation utilities
- `core/` — shared interfaces, configuration, and model abstractions
